I would use either the fully autonomous mode or the manual teleoperation mode. The advantage of the manual operation mode is how much faster it is compared to the other two modes. Part of this is due to the course being simple, and part of it is how difficult the setup for voice mode is. It only accepted a very specific phrase for red, which meant I had to redo a successful run three times. Autonomous mode probably wins overall because it took 80 seconds but required no other human input. Due to the constraints of the current voice model, it wouldn't be good for a routine handover.
